# MovieBook - JavaScript Movie Booking Demo

A beginner-friendly BookMyShow-style movie ticket booking website built with:
- HTML
- CSS
- Vanilla JavaScript

## Features
- Recommended movie cards
- Movie search
- Show-time selection
- Seat selection
- Occupied-seat simulation
- Maximum 6 seats
- Automatic price calculation
- Booking confirmation modal
- Booking ID generation
- Finish & Close behavior
- Responsive design

## Run
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Select a movie.
4. Select a show and seats.
5. Click Confirm Booking.
6. Click Finish & Close.

## Important
Browsers generally block `window.close()` for a normal tab that was not opened by JavaScript. The demo therefore attempts `window.close()` and provides a fallback message/navigation when the browser refuses to close the tab.

## Movie data
The movie names and ratings in this demo are sample content for a learning project. Replace them with current movie data and licensed poster images before using the app commercially.
